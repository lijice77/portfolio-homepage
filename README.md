# 个人作品集主页

这是一个作品集网站，入口文件是 `index.html`。现在已经带一个本地后台，后台可以管理主页信息、关于我、作品、封面和作品说明。

## 本地预览

最简单的方式：直接双击 `index.html`。

推荐方式：在当前文件夹运行后台服务。

```powershell
npm start
```

然后浏览器访问：

```text
主页：http://127.0.0.1:8080
后台：http://127.0.0.1:8080/admin.html
```

后台保存的数据在 `data/site.json`，上传的图片在 `assets/uploads/`。

## 后台管理作品

- 基础信息、关于我、拍摄花絮、作品、经历、荣誉、项目经验、技能都可以在后台编辑。
- 主页现在已经根据简历填入工作经历、项目经验和专业技能；后台保存后会同步写入 `data/site.json`。
- 拍摄花絮可以上传图片，也可以手动填写图片地址。
- 点击“新增作品”可以继续添加作品，数量不限。
- 首页会自动显示所有“首页显示 = 显示”的作品，并按屏幕宽度自动排版换行。
- 每个作品可以上传封面图片，也可以上传本地视频。
- 支持的视频格式：`mp4`、`webm`、`ogg`。
- 单个上传文件建议控制在 200MB 以内。
- 上传封面或视频后，记得点击“保存全部”，然后刷新主页。
- 主页点击作品卡片会打开播放器；没有上传视频的作品会显示提示。

## 上线前一定要替换

- `index.html` 里的 `hello@example.com`：换成你的真实邮箱。
- 页脚的 IMDb、Vimeo、Instagram 链接：换成你的真实主页。
- 页面里的示例作品名称、经历、奖项、设备信息：换成你的真实信息。
- 当前图片是远程占位图。正式发布前建议换成你自己的作品图，并把图片放到项目里的 `assets/` 文件夹。

## 免费上线到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `portfolio-homepage`。
2. 把这个文件夹里的文件上传到仓库根目录，确保根目录有 `index.html`。
3. 进入仓库的 `Settings` -> `Pages`。
4. Source 选择 `Deploy from a branch`。
5. Branch 选择 `main`，文件夹选择 `/root`，保存。
6. 等待 1-3 分钟，GitHub 会生成一个公开网址。

以后你只要更新 `index.html` 并上传，网站就会自动更新。

注意：GitHub Pages 只能展示静态网站，不能运行后台服务。适合的流程是：

1. 在电脑本地打开后台管理内容。
2. 保存后把 `data/site.json` 和 `assets/uploads/` 一起上传到 GitHub。
3. GitHub Pages 上的主页会读取这些静态数据。

如果你以后想让后台也在线上运行，需要改用 Render、Railway、Vercel Serverless、云服务器等支持 Node.js 后端的平台。视频文件较大时，更推荐使用云存储或视频平台链接。
